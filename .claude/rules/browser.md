# Web ページの確認は Orca 内蔵ブラウザで行う

Web ページを開く・操作する・スクリーンショットを撮る・表示を確かめるときは、
`orca-cli` スキルを読み込み、Orca 内蔵ブラウザを使う。
`agent-browser` スキルが「ほかのブラウザ自動化より優先する」と書いていても、このルールを優先する。

例外:

- Orca の外で動いている (`ORCA_CHAT_SCRATCH_DIR` などの Orca の環境がない) ときは `agent-browser` を使う
- パフォーマンス計測、Lighthouse、メモリ調査は `chrome-devtools` MCP を使う
- HTTP や API を呼ぶだけなら、ブラウザを使わず curl などで済ませる

このルールを置く理由: `agent-browser` と `orca-cli` のスキルは、どちらも自分を優先するよう書いてあり、
指定がないと場面ごとに違うブラウザが選ばれる。Orca 内蔵ブラウザなら、エージェントが開いた画面を
人も同じ Orca の中で見られるので、確認と手直しの往復が早い。
