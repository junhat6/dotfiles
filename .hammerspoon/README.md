# Hammerspoon ショートカットの系統と一覧

修飾キーの組み合わせから「何をするキーか」を思い出すための一覧です。現在の [init.lua](init.lua) と [modules](modules/) に基づきます。系統名は現在の割り当てを整理したもので、例外は末尾のレビュー表にまとめています。

`Alt` は macOS の `Option`（⌥）、`Ctrl` は `Control`（⌃）、`Cmd` は `Command`（⌘）です。文字キーの大文字表記は追加の Shift を意味しません。Shift が必要な場合は明記しています。Alt を含む組み合わせは Alt を先頭に表記します。

## 修飾キーで覚える

| 組み合わせ | 主な系統 | 覚え方 | 現在の例外・境界 |
| --- | --- | --- | --- |
| **Alt + 英字** | **アプリを直接開く・切り替える** | よく使うアプリへ一発で移動 | H/J/K/L は Karabiner の文字編集用で、アプリ登録不可 |
| **Alt + 数字** | **登録済み URL を直接開く** | 数字は URL の保存スロット | 「Alt はアプリ系」とだけ覚えると例外になる |
| **Alt + Shift** | **検索・一覧・管理の画面を開く** | 選択肢を出してから操作 | 数字は URL 登録、`,` / `.` はウィンドウの記憶・復帰 |
| **Alt + Ctrl** | **ウィンドウの配置・画面間移動** | 今のウィンドウを整える | H/L は文字編集、S は Capsomnia によるスリープ防止の切り替え |
| **Alt + Ctrl + Shift + H/L** | **単語単位で選択** | 単語移動に Shift を加えて選択 | Karabiner が処理 |
| **Ctrl + Shift + 数字** | **ウィンドウをデスクトップへ移す** | 数字は移動先のデスクトップ番号 | 今の設定に系統外の割り当てなし |
| **Cmd + Shift** | **貼り付けの拡張**（現在は V のみ） | V の貼り付けを履歴選択に拡張 | 選択画面なので Alt + Shift 系とも用途が重なる |
| **Cmd 単独修飾** | **標準操作の保護**（現在は Q のみ） | 終了キーを長押しにする | 独立した独自操作の系統というより、標準操作の調整 |

この表は Hammerspoon と関連する Karabiner 設定の範囲です。macOS や各アプリの同じ修飾キーすべてを、このルールで分類するものではありません。

## Alt + 英字：アプリへ直接移動

アプリが起動していなければ起動し、起動済みなら前面へ移動します。移動後はウィンドウ中央へマウスポインターを移します。

以下は [app_shortcuts.lua](modules/app_shortcuts.lua) の**初回設定**です。登録後の変更は端末ごとの `hs.settings` に保存されるため、README と実際の割り当てが異なる場合があります。

| キー | 初回設定のアプリ |
| --- | --- |
| Alt + A | ChatGPT |
| Alt + B | DBeaver |
| Alt + C | Claude |
| Alt + D | Discord |
| Alt + F | Finder |
| Alt + G | Google Chrome |
| Alt + I | Visual Studio Code |
| Alt + M | Muse |
| Alt + O | Obsidian |
| Alt + S | Slack |
| Alt + T | WezTerm |
| Alt + U | Orca |
| Alt + Z | zoom.us |

**Alt + M → Muse は dotfiles の初回設定に含まれます。** 現在の端末の登録も `hs.settings` に保存され、設定の再読み込み・Hammerspoon の再起動後も保持されます。初期化済みの別端末では、初回設定を更新しても既存の登録は上書きしません。

現在の登録一覧・変更・解除は **Alt + Shift + P →「登録済みアプリショートカットを管理」** で確認できます。メニューバーの `⌨︎` からも操作できます。

## Alt + 数字：保存した URL へ直接移動

| キー | 動作 |
| --- | --- |
| Alt + 1〜9 | 対応するスロットの URL を Chrome で開く |
| Alt + Shift + 1〜9 | 現在の Chrome タブを対応するスロットに登録・上書き |

保存先は端末ごとの `hs.settings` です。登録した URL 自体はリポジトリで共有しません。HTTP/HTTPS のページだけ登録できます。未登録スロットは、その旨を通知します。

URL ランチャーの右クリックメニューでも、登録・解除ができます。

登録済みのスロットへ保存するときは、現在と変更後のタイトル・URL を表示して上書きを確認します。Alt + Shift + 数字と右クリックからの登録に共通で適用され、キャンセルすると保存内容は変わりません。

## Alt + Shift：検索・一覧・管理

| キー | 動作 | 種類 |
| --- | --- | --- |
| Alt + Shift + P | 統合パレットを開く。アプリ登録・管理、ウィンドウ・URL・GitHub 検索への入口 | 管理・選択画面 |
| Alt + Shift + H | ショートカット一覧を開く。検索して操作も実行できる | ヘルプ・選択画面 |
| Alt + Shift + W | 開いているウィンドウを検索して切り替える | 検索・選択画面 |
| Alt + Shift + L | 開いている Chrome タブ、保存 URL、利用頻度順の履歴を検索する | 検索・選択画面 |
| Alt + Shift + G | アクセス可能な GitHub リポジトリを検索する | 検索・選択画面 |
| Alt + Shift + 1〜9 | 現在の Chrome タブを URL スロットに登録・上書き | **例外：直接登録** |
| Alt + Shift + , | 現在のウィンドウを1つ記憶する | **例外：直接登録** |
| Alt + Shift + . | 記憶したウィンドウへ戻る | **例外：直接移動** |

ウィンドウの記憶は設定の再読み込み・Hammerspoon の再起動で失われます。アプリや URL の保存スロットとは保存期間が異なります。

Alt + Shift + , で既に記憶しているウィンドウを変更するときも、上書き確認を表示します。検索画面を開くキーや記憶先へ戻るキーでは確認しません。アプリ登録の使用済みキーへの上書きは、パレット側でも確認します。

## Alt + Ctrl：ウィンドウの配置・画面間移動

| キー | 動作 |
| --- | --- |
| Alt + Ctrl + ← | 左半分に配置 |
| Alt + Ctrl + → | 右半分に配置 |
| Alt + Ctrl + Enter | 最大化（macOS のフルスクリーン化とは別） |
| Alt + Ctrl + C | 中央に画面の70%サイズで配置 |
| Alt + Ctrl + M | 次のモニターへ移動 |
| Alt + Ctrl + S | **例外：Capsomnia のスリープ防止を切り替える** |
| Alt + Ctrl + H/L | **文字編集：単語単位で左/右へ移動（Karabiner）** |

S は Capsomnia の起動が前提です。Capsomnia が監視する Caps Lock 状態を切り替え、スリープ設定への反映を確認します。

Capsomnia は共有 [Brewfile](../.config/dotfiles/Brewfile) に含まれます。個別に導入する場合は `brew install --cask capsomnia` を使います。管理者認証が必要です。インストール後はログイン時の自動起動用 LaunchAgent が登録されます。

## Ctrl + Shift + 数字：デスクトップへの移動

| キー | 動作 |
| --- | --- |
| Ctrl + Shift + 1〜9 | 現在のウィンドウを、同じ画面のデスクトップ1〜9へ移動 |

移動先のデスクトップが存在し、macOS の **Control + 数字によるデスクトップ切り替え**が有効になっている必要があります。フルスクリーンのウィンドウは対象外です。

**Ctrl + Shift + L の割り当てはありません。** URL ランチャーは **Alt + Shift + L** です。

## Cmd 系：標準操作の拡張・保護

| キー | 動作 |
| --- | --- |
| Cmd + Shift + V | クリップボード履歴を開き、選択したテキストを貼り付ける |
| Cmd + Q | 0.8秒長押しでアプリを終了する。短押しでは終了しない |

クリップボード履歴はテキスト最大50件で、設定の再読み込み・再起動で消えます。Finder は長押し終了の対象外です。

## Karabiner と共有するキー領域

入力は Karabiner で変換された後に Hammerspoon へ届くため、Hammerspoon に登録できても、変換元のキーでは呼び出せない場合があります。正本と割り当て図は [Karabiner の README](../.config/karabiner/README.md) を参照してください。

| キー | Karabiner 側の動作 | Hammerspoon 側での扱い |
| --- | --- | --- |
| Alt + H/J/K/L | ←/↓/↑/→ | アプリへの割り当て不可 |
| Alt + Ctrl + H/L | 単語単位で左/右へ移動（Alt + ←/→ を出力） | Karabiner が処理。Hammerspoon のウィンドウ配置とは別 |
| Alt + Ctrl + Shift + H/L | 単語単位で左/右へ選択を拡張 | Karabiner が処理 |
| Alt + N、Alt + Shift + N/M | 変換しない | N はアプリ用に登録可能。Shift 付きの N/M は Hammerspoon でも未割り当て |
| Alt + M | 変換しない | Muse を開く（初回設定） |

Alt + H/L の1文字移動に Ctrl を足すと単語移動、さらに Shift を足すと単語単位の選択になります。Alt + Shift + L は引き続き URL ランチャーです。

Tab の長押しは Alt、Caps Lock の長押しは Ctrl として使えます。単語移動は Tab + Caps + H/L でも操作できます。**右 Shift は Delete、右 Cmd は「かな」**に割り当てられているため、ここに載せた Shift/Cmd の組み合わせには左側のキーを使います。

## 系統から外れる・整理を検討したい割り当て

以下は**レビュー候補**です。割り当て変更の決定ではありません。用途のまとまりと既存の操作習慣を見比べて判断できます。

| ID | 現在の割り当て | どの基準で外れるか | レビュー時の選択肢 |
| --- | --- | --- | --- |
| R1 | Alt + 1〜9：URL を開く | 「Alt はアプリ系」を厳密にすると、URL は対象外 | 「Alt は保存先への直接移動、英字はアプリ・数字は URL」と定義して維持する／URL を別系統へ移す |
| R2 | Alt + Shift + 1〜9：URL 登録 | Alt + Shift の主用途は検索・一覧だが、これは保存内容を直接変更する | 「Alt の操作に Shift を加えると登録」として維持する／登録専用の組み合わせへ移す |
| R3 | Alt + Shift + ,：ウィンドウを記憶 | 選択画面を開かず、状態を直接保存する | 登録系へ寄せる／`,` と `.` の対として維持する |
| R4 | Alt + Shift + .：ウィンドウへ復帰 | 選択画面を開かず、ウィンドウを直接切り替える | ウィンドウ操作系へ寄せる／記憶・復帰の対として維持する |
| R5 | Alt + Ctrl + S：スリープ防止 | Alt + Ctrl の主な用途はウィンドウ配置。H/L の文字移動とも別用途 | 電源・常駐機能の切り替え用に別系統を作る／S だけ例外として維持する |
| R6 | Cmd + Shift + V：履歴選択 | 検索・選択画面という点では Alt + Shift 系に近い | Cmd + V との関連を優先して維持する／検索・選択画面を Alt + Shift に統一する |
| R7 | Alt + H/J/K/L、Alt + Ctrl + H/L、Alt + Ctrl + Shift + H/L：文字編集 | Alt のアプリ系、Alt + Ctrl のウィンドウ配置系と文字編集が同居する。実装も Karabiner と Hammerspoon に分かれる | 「文字編集用の予約領域」として明示して維持する／どちらかのキー領域を移す |

R1・R6・R7 は系統の定義次第で意図的な例外として扱えます。R2〜R5 は「Alt + Shift＝選択画面」「Alt + Ctrl＝ウィンドウ配置」と覚えたときに、操作を推測しにくい箇所です。Cmd + Q は標準キーの保護という説明で整合するため、変更候補には含めていません。

レビュー依頼では、例えば「R5 を電源系へ移す」「R1 は直接移動系という定義で維持」のように ID で指定できます。

## 設定とドキュメントを更新するとき

- 静的キーの正本は [init.lua](init.lua)。キーの追加・変更時はこの README の一覧とレビュー表も更新します。
- アプリの初回設定・登録処理は [app_shortcuts.lua](modules/app_shortcuts.lua)。利用中の端末では初回設定の変更だけでは既存登録は変わりません。
- アプリの登録は `appShortcutBindingsV1`、URL スロットは `urlLauncherDynamicSlotsV1` という `hs.settings` に保存されます。
- 実行中のキーの確認は Alt + Shift + H、アプリの実際の登録確認は Alt + Shift + P の管理画面を使います。ヘルプ一覧だけでアプリ登録の全件確認はできません。
- `.lua` の変更は自動で設定を再読み込みします。手動ではメニューバーの `⌨︎` →「Hammerspoon設定を再読み込み」を使います。
- Karabiner のキーを変更する場合は、そちらの README にある再生成手順に従います。
